# Triage Red-Flag Rules — v1.0 (Lane C)

> **Status:** Verified clinical draft · Sourced from WHO, MoHFW / NHM India, AHRQ ESI, and FIGO clinical guidelines.
> **Operational Rule:** When any red-flag rule fires, the triage engine immediately assigns `urgency = "emergency"`, `confidence = 1.0`, and routes to the rule's designated `department` without waiting for secondary routing.
